明日方舟 · 资源与资料工作台（Windows x64）

在可写目录中解压整个程序文件夹。保留 _internal 后，双击 ArknightsUnpacker.exe 即可离线使用，无需安装 Python 或 Node.js。

第一次使用

1. 用顶部的文件夹按钮选择《明日方舟》游戏目录，点击“扫描更新”。可从右上角菜单打开“扫描选项”更改检查顺序。
2. 在“资源浏览”的中间列表双击文件夹或资源包。鼠标侧键可前进和后退。按 Ctrl、Shift 点选或按住左键拖动，可勾选多项。
3. 勾选文件后点击“加入解包队列”。进入资源包后，单击对象在右侧预览，勾选所需项后点击“提取勾选对象”。
4. 在“干员资料”或“模组更新”选择资料后，可预览或导出 PNG、HTML 等格式。右上角菜单的“任务记录”提供进度与产物入口。

输出与升级

默认输出为程序旁的 exports 文件夹。“设置”位于左侧“玩法资料”下方，可修改输出目录、解包方式和报告格式。游戏目录仅作为输入。
程序旁的 data 保存设置、扫描和解析历史。升级时先退出程序，保留 data 与已有 exports。如果换到新程序目录，把这两个文件夹一起带过去。

界面操作和故障诊断见“使用指南.md”。依赖来源和许可见“第三方说明.md”。build-info.json 和 file-manifest.json 记录构建来源、版本与文件摘要。
