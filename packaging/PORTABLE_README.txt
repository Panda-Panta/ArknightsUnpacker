明日方舟 · 资源与资料工作台（Windows x64）

双击 ArknightsUnpacker.exe 启动，无需安装 Python。
请保留同目录的 _internal 文件夹，移动程序时移动整个文件夹。

0.1.10 界面更新：顶部“扫描选项”和“历史对照”按需展开；空列表提供下一步引导。
设置页底部固定显示“保存设置”。HTML目录随阅读位置定位，搜索支持Esc清除，窄屏横表支持键盘滚动。

第一次使用：
1. 选择《明日方舟》游戏目录。
2. 默认输出到程序旁的 exports 文件夹，启动时自动创建；可在“设置”自定义。游戏目录只读，不作输出位置。
3. 扫描后选中文件解包；干员／模组资料请先点“解析核心数据”。
4. 选择资料，预览或导出 PNG 与 PRTS 风格 HTML。
模组页可勾选多个或“全选当前筛选”，再“合并导出选中模组”；“清空勾选”可重置。
手动导出和预览优先全部勾选（含被筛选隐藏项），请留意计数；无勾选时使用选中行。
“合并导出本次新增”导出全部已确认新增，不受勾选／筛选影响，新增合集标题为“本次新增模组”。
0.1.4 的模组合集 PNG 默认一张自适应高度长图；在“模组PNG排版”可改为分页。
单图超过 8,000 万像素会提示用分页或减少选择，不静默裁切或分张。
所选模组在同一个 modules.html 内，全部模组连续展示，各级按类别横排对照。干员独立报告分页不变。
预览缩放不改变保存的 PNG 像素。
0.1.9 成功任务自动保留最近20条，可点击“清理成功任务”；失败与待恢复记录保留。
对象／资料临时预览在窗口释放、后台结束后回收；外部HTML保留到本程序退出。
正式导出和保存副本保留，预览不改写输出目录；保存原图请选择正式输出位置。
0.1.8 模组按类别横排未装备／1级／2级／3级；属性显示装备后值（该级总加成）。
潜能、召唤物和条件效果单列；各级属性是本级总加成，不重复叠加。旧报告需重新导出才含新说明。

0.1.7 在“设置 → 资料导出主题（PNG / HTML）”选择暗色或亮色，保存后重启保留。
PNG、HTML 及 HTML 批次目录共用所选调色板、字体层级和资料卡片；旧报告需重新导出。
离线 HTML 使用模板 2.3.0，与 PNG 共用黑色顶栏和青色分区。
全部技能和模组直接连续展示，不再选择技能或模组等级；分类对照表与各元素紧凑排列。
搜索显示命中与高亮，清除恢复原选择；展开／收起保留选项，打印以亮色展示完整内容。
无需联网；无 JavaScript 仍可读全部正文。未附本地肖像时不显示空占位。
旧 HTML 需重新导出才含新布局，不覆盖旧报告；已有 PNG／JSON 不作迁改。

首次没有更新前的历史基线，不能确认本次新增；完整解析后可留存快照。
使用说明详见“使用指南.md”；组件来源与许可见“第三方说明.md”。
本程序包为用户本机便携交付，未公开发布。

默认配置与历史数据：程序同目录的 data 文件夹。
默认输出：程序同目录的 exports 文件夹，不存在会自动创建。
显式 --data-dir 只改变数据目录，不改变默认输出；--output-dir 可指定输出。
旧 Documents/ArknightsExports 默认配置自动改为 exports，其他自定义路径保留；旧输出文件不移动。
再次启动直接读取上次扫描、解析和查看状态；点击扫描后与完整基线比较。
首次升级会非覆盖迁入旧 %LOCALAPPDATA%\ArknightsUnpacker 历史，原文件保留。
升级时保留 data 与已有 exports；若解压到新目录，请退出程序后复制这两个文件夹。
游戏图片按原始像素保存，预览缩放不影响保存；单图平铺，多图按包建目录。
build-info.json 和 file-manifest.json 记录本次构建来源、版本与文件摘要。
