# 明日方舟关卡预览器

双击 `ArknightsLevelPreview.exe`，选择明日方舟 PC 客户端目录并扫描。程序读取当前资源清单和关卡索引。按关卡分类和章节筛选，或搜索游戏内编号。勾选「仅看新增」可查看相对上次完整扫描新增的关卡。

双击关卡打开地图预览。支持作战指标的关卡可先选择指标。选中关卡后会后台准备回放资源。「播放出怪」打开原生回放，支持拖动进度、1×／2×、空格暂停及 Esc 退出全屏。回放使用当前客户端的原版场景和动画，并按无部署条件计算波次。依赖未模拟的实战触发时，窗口会显示具体原因。

程序使用同目录的 `data/` 保存扫描、设置和回放缓存，`exports/` 用于导出。可用 `--data-dir`、`--output-dir` 改用独立路径。

新建原生缓存需要本机 Microsoft Edge，以及 `pixi.min.js` 和 `pixi-spine.umd.js`。将使用者已准备的组件放入 `data/level-preview-runtime/`，或用 `--runtime-dir` 指定组件目录。Godot 已随程序提供，原始地图和角色由使用者的游戏客户端读取。
