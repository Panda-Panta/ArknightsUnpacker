## 本机真实数据范围

输入共 16,878 个文件；数据版本 **78.2.0**，资源版本 `26-10-14-13-44-12-52990322`。实际 IDX 包含 15,383 个包、196,352 项逻辑资源。12 张核心及依赖表构成一致快照，解析得到 **434 项干员资料、513 个正式模组**；资料项包含形态，不能解释为不同人物总数。

克莱门莎的实际满养成无模组样本为：HP 2720，ATK 920 + 110 信赖 + 35 潜能 = 1065，DEF 371，MR 10，部署费用 23 − 2 潜能 = 21，再部署 70 秒，阻挡 2，攻击间隔 1.2 秒；含三项专三技能和两项后勤技能。代表模组还覆盖本人／召唤物作用域、可见升级天赋与玩法条件。

独立审查发现的引擎、领域、IO、报告和 GUI 问题已修复并在各自范围复核，包括实际解码字节的摘要绑定、显式透明遮罩、Spine 对象选择、模组作用域、完整基线保护、排序后选择身份、跨干员模组状态、取消与任务恢复。审查范围内没有已实证而未关闭的产品问题；这不等于对所有游戏资源和未来版本作保证。
