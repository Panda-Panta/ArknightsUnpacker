# 明日方舟资源与资料工作台 · 使用指南

Windows x64 便携程序入口为 `ArknightsUnpacker.exe`。保留同目录的 `_internal` 文件夹，双击即可离线使用，无需安装 Python 或 Node.js。扫描与解析历史保存在程序旁的 `data/`，移动时一并带走它和已有输出。测试覆盖见 [验收摘要](ACCEPTANCE.md)。

## 第一次使用

1. 将程序文件夹解压到普通可写位置，启动 `ArknightsUnpacker.exe`。
2. 点击顶栏路径框右侧的文件夹图标，选择游戏根目录、`Arknights_Data`，或识别到的初始／热更资源根，然后点击“扫描更新”。只选择一层资源时，扫描覆盖该资源范围。
3. 默认先检查干员和模组，再扫描资源文件。右下角“工作台操作 → 扫描选项”也可选“仅检查干员／模组”或“仅扫描资源文件”，并调整最近更新时间与严格校验。缺少核心表时会保留解析诊断，默认模式仍会继续扫描文件。取消优先检查会结束本次流程。
4. 在左栏“资源浏览”定位和解包文件。检查资料后可打开“干员资料”或“模组更新”，也可从右下角菜单单独“解析核心数据”。“设置”位于左栏“玩法资料”下方，可选择解包类型、报告格式和输出目录。默认输出为程序旁自动创建的 `exports/`，请选择游戏目录以外的输出位置。

游戏目录只读。程序不会移动游戏文件、替换游戏资源、读取账号或存档，也不需要先启动游戏。

再次启动会读取上次扫描、解析结果和变化记录。点击“扫描更新”会按已保存的检查顺序读取当前资料或文件，并与对应完整基线比较。源游戏盘暂时离线时，已保存资料仍可查看。解包需要访问原文件。

拖动顶栏左侧的应用名称或旁边的空白处可移动窗口，双击可最大化或还原。拖动窗口边缘或四角可调整大小。顶栏右侧提供最小化、最大化／还原和关闭。点击旁边的月亮／太阳按钮可切换工作台的浅色和暗色，重启后会恢复上次选择。Windows 文件对话框沿用系统外观。

“设置 → 常规 → 资料导出”中的“导出主题”单独控制新生成的 PNG、HTML 及 HTML 批次目录。

右下角状态栏提供“任务记录”按钮和“工作台操作”菜单。菜单还可打开“资源快照与历史”和输出目录。修改设置后点击底部的“保存设置”。

## 浏览资源与最近更新

“资源浏览”把文件夹和资源文件放在中间列表。双击文件夹进入，用面包屑回到上级，也可用鼠标侧键前进或后退。单击一行在右侧查看路径、用途、来源及诊断。使用下拉框切换资源来源。

- **原始文件 · 全部来源**：浏览实际物理文件，适合有意提取历史底包。
- **当前生效资源**：按当前清单解释资源来源；缺失、旧底包、可选资源与未确认覆盖会保留状态。未安装的热更资源不会被无提示地当成旧底包。

点击列标题可按名称、用途、类型、大小、修改时间、创建时间、首次观测或状态／来源排序，再点一次切换顺序。“列设置”可调整列的显隐与顺序，也可开启“仅显示 .ab 文件”。大小按实际字节排序，时间按原始值排序。创建时间取自本机文件系统，首次观测取自本工具首次扫到该路径的时间。旧扫描缺少创建时间时，重新扫描可补齐。

可按关键词搜索名称、路径或用途。选中“剧情插图”“干员头像”等具体用途时，按当前来源在全库查询，可叠加关键词和 .ab 筛选。切回“全部用途”后，范围由面包屑和“包含子目录”决定。右侧的“解包此文件夹”会递归处理选中的文件夹。

资源与包内对象列表均可用复选框勾选。Ctrl + 左键切换单项，Shift + 左键按本页显示顺序勾选范围，按住左键拖动可框选本页。Ctrl + 左键拖动会把框中的行加入已有勾选。资源列表超过一页时，可用“勾选全部结果”一次选中全部匹配文件。

### 查看包内对象

双击支持的资源包，或点击右侧“查看包内对象”，进入包内列表。可按名称或 ID 搜索，按图片、音频、视频、文本或其他类型筛选，也可按对象名称、类型、大小或 ID 排序。Unity 对象大小是包内序列化大小，流式载荷与导出文件可有不同大小。独立媒体显示源文件字节数。

点击一个对象即可在右侧预览。图片可缩放和“保存原图…”，可播放的音视频提供播放、暂停与进度条；文本和受支持的数据可直接阅读。一个对象生成多份产物时，用右侧下拉框切换。能否播放取决于编码，失败时可查看诊断或选择“使用系统播放器打开”。勾选所需对象后点击“提取勾选对象”，以底部计数为准，筛选隐藏的勾选项也会提取。整包处理请返回资源列表后勾选包文件。

受支持的独立图片、音频、视频、文本、USM 和 IDX 也可从“预览文件”打开。对象列表与临时预览按需复用隔离解码进程，逐次读取源文件。切换对象或返回资源列表时，程序释放已不用的预览，后台结束后回收缓存。

### 查看更新记录

“更新记录”默认显示最近写入或基线变化的并集，可以按显示范围、目录用途、资源来源、关键词和 .ab 筛选。默认“排除已删除文件”，可取消查看删除历史。可双击仍在的文件查看对象和右侧预览，或用“全选当前结果”批量处理。“导出所选包内图片”使用自动图片提取，按原始像素保存 PNG。“解包所选文件”使用设置中的资源类型和解包方式。

最近时间窗口默认 24 小时，可从右上角“扫描选项”调整。此页依据本机写入时间和完整文件快照比较。严格校验会重新计算资源摘要，耗时更长。首次完整扫描建立文件基线，新增干员需另有可比较的资料快照。

### 制作 AVG 角色表情

0.1.25起，AVG角色图片会读取角色配置中的 `sprite / alphaTex` 引用补齐透明通道，同时适用于图片预览和正式图片解包；Material引用、图片自身Alpha和原始序列化导出继续保留。程序按引用配对，不按纹理名称猜测；缺失、冲突或外部依赖会给出诊断。

在“资源浏览”进入 `avg/characters`，勾选角色包，从“加入解包队列”右侧的下拉菜单打开“表情差分制作”。一个角色包可在工作区手动制作，也可批量导出。

- **自动批量**：窗口中的“批量导出全部表情”按各组原始配置导出底图、表情及整幅姿态，不使用手动偏移。也可在资源表多选角色包后点击“表情差分制作…”，批量处理各包。
- **手动制作**：选择角色组、底图和表情，调整左上角像素坐标与表情宽高后会自动预览，连续修改会合并生成最终效果。预览支持缩放、适应窗口，成功后才能“导出当前合成”。改变参数会使旧预览和导出确认立即失效；“恢复本组配置”还原位置和尺寸。整幅姿态直接替换全图，不应用表情贴图坐标。

表情工作区在读取配置后生成初始预览，切换组、底图、表情，调整位置尺寸或恢复配置时自动更新。

合成恢复Sprite原始逻辑画布及裁剪偏移，PNG保留透明。负坐标和部分超出画布可裁剪，完全没有交集会报错；图集、降采样或无法确认的外部引用不会猜测合成。预览缓存关闭后回收，不改正式输出设置，当前页面保持。导出任务保留配置、来源对象及失败诊断；重试保守重做未完成的来源，已存在产物保留。

## 解包任务

在“设置”中选择资源类型与自动／原始导出方式，勾选文件后点击“加入解包队列”。从右上角菜单进入“任务记录”，可查看状态与诊断、重试失败任务、打开所选产物或输出目录。关闭程序时如有任务，程序会先请求取消并等待工作进程结束。

每次解包创建独立 `extract-时间-任务ID` 批次。单图包的 PNG 直接放批次根目录，多图包才创建源包子目录；只选一张图片也平铺。自动整包导图中，经引用、全幅尺寸和像素一致性确认的 Texture／Sprite 同图只导出一次；显式选择对象时尊重选择。Spine 保留整组相对目录，文本、音频及原始对象保持各自分组。同名使用对象 ID 和额外序号避免覆盖。`extraction-result.json` 保存输出、错误及跳过原因，后续任务不会覆盖旧批次。损坏包或不支持对象可单独失败。

游戏图片保存解码后的原始像素；Sprite 保留自身裁切尺寸，不被资料排版宽度或预览缩放重采样。对象预览可缩放，点击“保存原图…”复制原文件，保留像素、透明度及元数据；已存在目标不会被覆盖。RGB 与明确引用的 Alpha 合并时保持 RGB 尺寸，仅对齐遮罩。关闭对象窗口或切换到下一次预览时，已不再使用的临时目录自动回收；后台仍在写入时等待任务结束。保存副本请选择正式输出目录，临时预览根目录不接受“保存原图”的目标。

0.1.9 起，成功任务自动保留最近20条，启动和任务结束时清理更旧记录；也可点击“清理成功任务”。仅移除任务清单与检查点，不删除正式导出。失败、取消、中断、部分完成，以及恢复任务仍依赖的祖先记录保留。重启后，未结束任务显示“已中断”，不会自动执行；选择原任务可手动重试或重新查看仍存在的正式产物。“暂停队列”只阻止开始后续任务，当前任务继续到结束；中断当前任务请点“取消”。

解包恢复依据该任务自己的完成事件、结果清单与仍然存在的产物，只继续未完成来源／对象；崩溃中途单独写出的文件不等于整个对象完成。无法确认完整性的 Spine 组会作为未完成组重新处理，旧文件保留。恢复历史报告前需先从原安装加载对应的数据快照；入队及实际执行时都会核对安装与快照，来源不同会提示重新选择导出。报告取消后，已成功生成的产物与部分结果清单会保留；快照内容未加载时，既有 PNG／HTML 仍可从任务页重新查看。

图片、文本、Spine、音频的支持以对象实际解码结果为准。音频无法转换为可播放格式时可能保留 `.audio` 源文件并附诊断；不得将源文件后缀改为 WAV 后宣称可播放。Spine 可能仅保留原始组成文件，完整贴图组、透明通道合并和可用性须看本次结果。

USM 视频在**自动模式**下通过 WannaCRI 分离视频／音频流，本机样本生成 IVF 视频和 SFA 音频；原始模式才复制 `.usm` 源文件。程序如在系统 `PATH` 找到可选的 `ffmpeg`，会复制视频流、将音频转换为 AAC 并封装为 MKV；如找到 `ffprobe`，也会记录流探测结果。未找到 FFmpeg 时仍保留分离后的原始流，并在 `.media.json` 记录转换能力缺失；封装失败也保留原始流及诊断。此包不附 FFmpeg／FFprobe，可自行安装后将其目录加入 `PATH`，它们不是程序启动或 USM 分流的前置条件。本机样本已通过 FFprobe 流核对及 FFmpeg 前一秒音视频实际解码；这不代表全部视频均已完整播放验收，具体覆盖见 M9／引擎验收记录。

## 干员、模组与新增识别

先解析当前核心数据，然后可按名称或稳定 ID 搜索资料。干员静态面板默认最高精英／等级、满潜与满信赖，可选择一个模组。资料包括属性及加成来源、潜能、天赋、技能、后勤和模组。缺失或未解析的效果以文字提示，完整诊断保存在 JSON。干员和模组详情展示当前资料，右上方的“资料目录”可跳转实际章节，如属性、技能、天赋、后勤和模组。

职业分支名称直接取自同一份游戏数据，例如能天使的“速射手”；缺少名称时标为未确认。后勤区列出所有精英阶段和等级解锁的全部技能，早期版本和升级版本都保留名称、设施、完整说明与解锁条件，不受面板培养选择影响。同一位置的升级技能会替换旧技能，列表不表示它们同时生效。已有资料快照可直接重新浏览或导出，无需重新扫描。

0.1.8 起，每个模组按属性类别横向比较“未装备、1级、2级、3级”，不再分别重复介绍三个等级。例如攻击一行可显示 657、684（+27）、692（+35）、698（+41）；括号是对应等级的模组总加成，不累加前级。部署费用减少保留负号。对照使用相同培养条件，不受干员面板当前选中的另一模组影响。

“特性与天赋”同样用四列横向比较，重复原文简写为“同未装备／同1级”等，直接指向首次完整说明；潜能提升单列。召唤物、限定玩法和地图条件仍在对应效果下展示，战斗中的百分比或条件效果不加入常驻属性面板。尚未解锁或属于限定模组时，不给出无条件装备后的面板。预览与 PNG／HTML／TXT 使用同一份对照；旧导出是静态文件，需要重新导出，原文件保留。原快照可直接生成新对照，无需重新扫描或解析。

首次解析没有可比较的历史基线，条目为历史未知。要识别真正的本次新增／修改：

1. 在一次完整解析后，从右上角菜单打开“资源快照与历史”，使用“导出当前快照…”留存基线。
2. 游戏更新后重新扫描并解析。在“资料快照”中选择完整的历史快照，点击“比较所选快照”；也可用“导入历史基线…”选择本工具先前导出的同服 JSON 快照。
3. 两个资料页都可选择“仅看新增”。有已确认的新增条目时，“导出新增资料”可导出全部已确认的新增条目。模组的新增合集标题为“本次新增模组”。

可用资料列表的复选框勾选多条，也可用表头复选框勾选全部筛选结果。预览与导出优先使用全部勾选项，包含筛选后隐藏的条目。没有勾选时使用当前所选行。勾选多个模组后，“导出选中资料”会合并为一份模组资料。

“设置 → 常规 → 运行与历史”中的“数据区服”默认为未知。同一安装位置可比较本地内容。确认当前数据和导入基线都属于简体中文／国服后，可选择相应区服，保存设置后重新解析，再导入或比较历史快照。跨来源比较需要可比区服声明。

文件最近写入、资源版本变化和业务实体新增是三种不同信息。新增 ID 只代表数据中新出现；尚未确认可获取的角色不代表已正式开放。手动选择现有干员和模组始终可以导出，不必伪造历史基线。

当前 PC `building_data` 有五个新增根字段，其语义尚未解析，程序保留未知字段证据和原始来源；已知结构中的干员后勤等资料可以解出。该限制不能被理解为整张后勤表不可解，也不能据此把未知字段补成“无效果”。

## 玩法资料

扫描资源后打开“玩法资料”，可查看当前清单识别到的玩法、版本和资源路径。已安装卫戍协议数据时，可以选择赛季，查看策略、盟约、调度和关卡文字条目。关卡条目包括尺寸、路线数量、波次数和敌人 ID。其他已识别玩法可查看资源索引。

## PNG 和离线 HTML

预览或导出时会留在当前资料页。主动预览、导出、扫描、解析与解包的进度和结果可从右上角菜单的“任务记录”查看。

0.1.21起，天赋中特殊名词的完整解释显示为对应表格下方的小字号注释，不新增章节或目录项；原有数值、潜能标注和条件括号保留。已有官方潜能标注时不再重复提示“部分潜能效果未确认”，未标注但有前后原文时提供基础／当前潜能对照，确实缺少证据的项目继续标明未确认。已有静态报告需重新导出。

在“设置 → 常规 → 资料导出”中打开“导出字体”下拉框搜索并选择已安装的 Windows 字体，支持按样式选择 TTC 中的字形。保存后用于后续 PNG 与 HTML 导出。

用“预览选中资料”打开预览。可调整主题或从“本次资料字体”下拉框选择系统字体并重新排版，按“预览文件”切换生成的 PNG 和其他产物。预览成功后，“正式导出”使用当前预览选择的主题和字体。预览中选择的样式仅用于本次资料。

HTML 及批次目录内嵌所选字体，TTC 会提取当前字形。重新导出时需要原字体文件；可在设置中恢复默认字体。关闭预览会释放文件缓存，已在外部浏览器打开的 HTML 保留到程序退出。

在设置中选择格式、PNG 画布宽度、字号和导出主题后，可在资料页点击“导出选中资料”。画布宽度与字号控制新生成的 PNG，HTML 随浏览器自适应。多份资料会生成索引和 manifest。PNG、HTML、JSON 和 TXT 共用当前报告数据，保留模组未装备及各等级的当前属性和效果。PNG、HTML、TXT 面向阅读，JSON 保留完整字段和来源。每次正式导出创建独立批次。

0.1.7 起，两种格式使用同一份配色和字体层级：黑色页眉、青色分区、对应主题的资料卡片、表头与交替行。资料分区顺序相同，PNG 完整呈现全部内容，HTML 直接展示全部技能和模组，并保留搜索、折叠及打印。选择亮色时使用白色资料面板；选择暗色时使用深蓝灰资料面板。切换主题后需重新导出，不会改写已有 PNG 或 HTML。

0.1.4 起，模组页单独导出的合集 PNG 默认合为一张自适应高度长图，包含所选模组的各级属性和天赋。在“设置 → 模组PNG排版”可选择单张长图或分页，保存后重启仍保留该选项。单张图超过 8,000 万像素时会明确提示改用分页或减少选择，不会静默裁切内容或改成多张；选择分页则按资料分页高度输出。干员独立报告的分页行为不变，模组排版选项也不改变干员报告。预览缩放只影响屏幕显示，不改变保存的 PNG 像素。

预览包含 PNG 与 HTML，并遵循已设置的其他格式。临时文件写入数据目录 `previews/`，正式产物可在任务记录或输出目录中重新打开。

HTML 为单文件离线资料页。可从预览对话框打开选中的 HTML，也可双击正式文件在浏览器查看。文件内嵌页面内容、样式、脚本和可用图片。批次的 `index.html` 用于跳转同批报告，移动批次时保留相对目录。

合并导出的全部所选模组位于同一个 `modules.html` 中，同页直接展示全部模组及各级对照，仍为单文件离线资料。HTML 模板为 2.3.0，沿用 PRTS 资料页的内容层次与右侧目录，并使用当前所选亮色／暗色主题。没有附带本地肖像时不显示空白占位。页面不是 PRTS 官方页面，也不通过在线站点补齐未解析字段。

- 全部技能直接连续展示，无需切换；就近目录可跳转到技能正文。
- 全部模组连续排列，每个模组一份简介与分类横表；不提供等级选择，不按等级隐藏内容。召唤物用短编号区分，完整内部标识仅保留在JSON中。
- 搜索显示命中数、高亮与无结果提示；清除后恢复全部内容及搜索前的折叠状态。
- 统一展开／收起资料；每个模组只有一个折叠标题，分类表之间减少空白和重复边框。
- “打印”按钮或 Ctrl+P 均以适合纸张的亮色打印完整内容；打印结束后恢复屏幕所选主题、原来的搜索与折叠状态。
- 禁用 JavaScript 时仍展示全部正文，隐藏需要脚本的互动栏。

已导出的 HTML 是静态快照，升级程序后需重新导出才能使用新布局，旧报告不会被覆盖。旧 PNG／JSON 仍可读取，不作迁改。各版本的真实浏览器、窄屏及打印验证范围见验收摘要。

## 数据保留、升级与诊断

“保存原图…”保存所选 PNG 的原始文件。缩放仅改变显示大小。

0.1.2 起默认输出目录：EXE 同目录的 `exports/`；源码运行时为项目根的 `exports/`，启动时不存在会自动创建。它不随启动工作目录或显式 `--data-dir` 改变，也不写入 `_internal`。例如安装于 `D:\Tools\ArknightsUnpacker` 时，默认输出为 `D:\Tools\ArknightsUnpacker\exports`。可在设置中或通过 `--output-dir` 指定其他输出目录；已有文件与历史批次保留。

默认应用数据目录：EXE 同目录的 `data/`；源码运行时为源码根的 `data/`，不随启动工作目录改变。“设置 → 打开数据目录”可进入，显式 `--data-dir` 只改变这项数据目录，不改变输出默认位置。主要内容包括：

| 内容 | 用途 |
| --- | --- |
| `settings.json` | 游戏／输出路径、扫描方式、区服、解包及报告选项 |
| `workbench-web/` | 当前资源目录、来源、列设置、排序等工作台浏览偏好 |
| `catalog.sqlite3` | 扫描、解析、安装信息和上次准确的文件／实体比较结果 |
| `catalog.sqlite3.v*-backup-*.sqlite` | 数据库升级前备份 |
| `jobs/<任务 ID>/` | 隔离工作进程请求、结果、`events.jsonl`、`worker.log` 及必要时的 `diagnostics.log` |
| `queue/` | 最近20条成功历史，及失败／待恢复任务与依赖检查点；旧成功元数据自动清理 |
| `preview/` | 资源对象临时预览，窗口释放且后台结束后回收 |
| `previews/` | 临时资料预览，关闭后回收，外部HTML保留到程序退出 |

首次从 0.1.0 升级且程序旁尚无已有数据时，非覆盖迁入旧 `%LOCALAPPDATA%\ArknightsUnpacker` 的配置、数据库和任务历史；旧位置原文件保留，可重建缓存不迁入。中断迁入后可继续，已存在的新数据不被覆盖。

旧版配置中仍使用默认 `Documents/ArknightsExports` 时，自动改用程序旁 `exports/`；其他自定义输出路径保留。只更新保存位置，不移动或删除旧目录内的导出文件，需要时仍可从旧位置读取。

用户正式输出、导出基线和历史报告不会自动清理。下次启动会回收有应用标记且未被其他实例占用的遗留预览；旧无标记目录还需对应预览任务和完整文件证据。未知归属、含链接、仍可能在用或存在额外文件的目录保留并提示诊断，不扫描其他输出目录。旧对象预览曾可能污染输出设置，只有历史请求明确证明当前保存路径是该临时目录时，才恢复程序旁 `exports/`；其他自定义路径保留。升级到新程序目录时，先退出程序，再复制整个 `data/` 到新目录旁；默认输出也需一并保留 `exports/`。不要用空目录覆盖原数据。迁移前备份数据和输出；SQLite 存在 `-wal`、`-shm` 时也应一起保留。不保证跨未知数据版本兼容。目录不可写时显示实际路径错误，可把程序移到可写位置；数据目录可用 `--data-dir` 调整，输出目录可用 `--output-dir` 调整，两者独立，不会静默改存临时目录。

发生错误时先看“任务记录”的诊断，以及对应 `worker.log`、`diagnostics.log`、`result.json`、`extraction-result.json` 和报告 manifest。保留程序版本、发生时间、资源相对路径和错误文本。分享日志前检查本机绝对路径。解码失败可能来自格式或 schema 变化、资源未安装、版本不一致或文件损坏。启动错误与运行时异常日志的位置以实际启动提示为准。需隔离试用数据时可从终端启动 `ArknightsUnpacker.exe --data-dir <独立数据目录>`，并可用 `--game-root`、`--output-dir` 指定此次输入／输出。

## 从源码运行与重建

源码开发与构建使用 Python 3.12 x64、uv、PowerShell 7 以及 Node.js（含 npm）。

```powershell
uv sync --locked
pwsh -File scripts/dev.ps1
pwsh -File scripts/verify.ps1
pwsh -File scripts/build.ps1
```

先用 `uv sync --locked` 安装 Python 依赖。`dev.ps1` 和 `build.ps1` 调用 `build-frontend.ps1`，按 `frontend/package-lock.json` 安装所需 npm 依赖并生成本地页面。`verify.ps1` 默认排除 `local` 标记测试，使用 `-IncludeLocal` 可包含需要本机游戏输入的测试。构建默认先验证，候选目录为 `dist/<版本>/ArknightsUnpacker`。构建临时文件位于 `.work/build/<任务 ID>`。

HTML 的开发验收入口为 `node scripts/verify-html.cjs --html <导出的HTML路径> --output <证据目录>`，通过真实浏览器检查离线报告。脚本需要本机 Node.js 与 Playwright；已有 Playwright 安装可通过 `NODE_PATH` 指定其 `node_modules` 目录。它们只用于开发验收，不是便携程序或离线 HTML 的运行依赖。

`build-info.json` 记录版本、精确依赖、上游提交与源码文件摘要；`file-manifest.json` 及 `SHA256SUMS.txt` 记录程序包文件摘要。无 Git 时来源如实记录为工作区文件清单。手动修改程序文件后需重新构建并重新验收；不要将预检目录当作正式发行候选。

0.1.10 的离线资料页明确标注本地档案。右侧目录随阅读位置标出当前分区，键盘可跳过导航进入正文；搜索框按 Esc 清除搜索。窄屏表格只在表格区域横向滚动，模组项目列保留在左侧，溢出时显示滚动提示，聚焦后可用方向键查看；页尾可返回页首。亮／暗主题、全文打印、无脚本完整正文和全部技能／模组连续展示保持。旧HTML需重新导出。
